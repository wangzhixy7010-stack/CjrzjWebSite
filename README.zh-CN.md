# 重庆市规划展览馆网站 — 中文说明

## 本地开发

```bash
npm install
npm run dev
```

浏览器访问 http://localhost:3000 。

## 工程定位

本仓库是**产品站**代码，不是克隆模板。  
`/clone-website` 能力已安装到用户目录，见英文 README「再次克隆其他网站」一节。
